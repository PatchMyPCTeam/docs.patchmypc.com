# Overview

_Applies to: Patch My PC Publisher V2.x_

The **Advanced** tab contains configuration options used to customize the Publisher behavior beyond standard publishing settings. These options allow administrators to control proxy configuration, content storage locations, logging behavior, script execution safeguards and other environment specific requirements.

<figure><img src="../../../.gitbook/assets/image (3930).png" alt="Advanced tab" width="545"><figcaption></figcaption></figure>

The settings in this tab are typically used for specialized scenarios, troubleshooting, performance tuning, or to align the Publisher with organizational infrastructure and security standards.
