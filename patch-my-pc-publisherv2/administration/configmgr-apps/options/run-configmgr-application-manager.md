# Run ConfigMgr Application Manager

_Applies to: Patch My PC Publisher V2.x_

The **Run ConfigMgr Application Manager** button is used to view and manage applications in ConfigMgr that were created using the Publisher. It provides a centralized interface to review application properties, deployments, task sequence usage and dependency relationships before performing application cleanup.

![Run ConfigMgr Application Manager](/_images/image-(4014).png "Run ConfigMgr Application Manager")

For more information about how to use this utility, see: [ConfigMgr Application Manager](../form-controls/configmgr-application-manager.md).
