# Overview

_Applies to: Patch My PC Publisher V2.x_

The **ConfigMgr Apps** tab is where you select which third-party applications should be published to ConfigMgr. Products enabled here determine which third-party applications the Publisher will publish and maintain within your environment.

![ConfigMgr Apps Tab Overview](/_images/image-(489 "ConfigMgr Apps Tab Overview") (1).png>)

Third-party applications appear in the **Software Library > Application Management > Applications** node in the ConfigMgr console.

![Applications appear in the Application Management view](/_images/image-(490 "Applications appear in the Application Management view") (1).png>)

Additional behavior related to application publishing can be configured using the [**Options**](options/) button on the ConfigMgr Apps tab.
