# Patch My PC Publisher

_Applies to: Patch My PC Publisher V2.x_

Official product documentation for Patch My PC Publisher, our on-premises based solution. "The Publisher" is a lightweight Windows application that helps you to create, update and manage applications in Microsoft ConfigMgr, WSUS and Intune.
