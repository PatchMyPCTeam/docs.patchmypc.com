# Language Support in Patch My PC Publisher and Cloud

_Applies to: Publisher and Patch My PC Cloud_

Both Publisher and Patch My PC (PMPC) Cloud support the following languages:

| Code | Language          |
| ---- | ----------------- |
| cs   | Czech             |
| da   | Danish            |
| de   | German            |
| en   | English           |
| fi   | Finnish           |
| fr   | French            |
| nb   | Norwegian Bokmål  |
| nl   | Dutch             |
| nn   | Norwegian Nynorsk |
| sv   | Swedish           |
