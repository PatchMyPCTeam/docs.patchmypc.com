{% hint style="danger" %}
**Important**

Different right-click customization options apply to different Microsoft management platforms and at different levels in Publisher (All Products, Vendor, or Product). These are detailed in the **Applies to:** section of each right-click customization.

Any customizations you configure are automatically carried forward to future update or application versions that Publisher publishes, ensuring consistent behavior without requiring repeated manual configuration.
{% endhint %}
