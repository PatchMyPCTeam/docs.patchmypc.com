# Show Staged Content Repository option in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_\
_Available at level: All Custom Products, All Products, Vendor, Product_
\
_Available on tab: ConfigMgr Apps, Intune Apps, Intune Updates_

The **Show Staged Content Repository** right-click option in Patch My PC (PMPC) Publisher opens the **Files in the service Staged Content Repository** window, which displays the contents of the Staged Content Repository.
