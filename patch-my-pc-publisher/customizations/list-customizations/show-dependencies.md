# Show Dependencies option in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_\
_Available at level: All Custom Products, All Products, Vendor, Product_\
_Available on tab: WSUS Updates, ConfigMgr Apps, Intune Apps, Intune Updates_

{% hint style="danger" %}
**Important**

This article has not been updated for Version 3.x. Once it has, this banner will be removed.
{% endhint %}

The **Show Dependencies** option in Patch My PC (PMPC) Publisher shows any dependencies for the selected item.

For example, in _Tree View,_ the Product Tree shows the chain icon beside **3CXPhone for Windows (MSI-x86)** indicating it has one or more dependencies.

<figure><img src="../../../.gitbook/assets/image (4725).png" alt="Chain icon beside 3CXPhone for Windows (MSI-x86)" width="299"><figcaption></figcaption></figure>

Right-clicking this product and clicking the **Show Dependencies** option opens the **Dependencies for <**_**product\_name**_**>** dialog, which shows all dependencies for this product.

<figure><img src="../../../.gitbook/assets/image (4726).png" alt="Dependencies dialog box" width="448"><figcaption></figcaption></figure>

In _Grid View_ for the same product, the Product Tree shows the chain icon beside **3CXPhone for Windows (MSI-x86)**, indicating it has one or more dependencies.

<figure><img src="../../../.gitbook/assets/image (4727).png" alt="Grid View showing dependencies" width="563"><figcaption></figcaption></figure>

Right-clicking this product and clicking the **Show Dependencies** option opens the same **Dependencies for <**_**product\_name**_**>** dialog showing all dependencies for this product.
