# Overview of Advanced Settings in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Advanced** tab of Patch My PC (PMPC) Publisher contains configuration options that customize Publisher's behavior beyond standard publishing settings. These options allow administrators to control the various settings listed in this section.

The settings in this tab are typically used for specialized scenarios, troubleshooting, performance tuning, or to align Publisher with organizational infrastructure and security standards.
