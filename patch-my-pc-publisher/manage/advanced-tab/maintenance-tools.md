# Maintenance Tools category of Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Maintenance Tools** category on the **Advanced** tab of Patch My PC (PMPC) Publisher allows you to configure:

* [ConfigMgr Duplicate Resolution](maintenance-tools.md#configmgr-duplicate-resolution)
* [Intune Tenant Mismatch Checker](maintenance-tools.md#intune-tenant-mismatch-checker)

## ConfigMgr Duplicate Resolution

The **CONFIGMGR DUPLICATE RESOLUTION** section contains the **Duplicate resolution** tool, which you can run by clicking **Open Resolution Tool**.

<figure><img src="../../../.gitbook/assets/image (1450).png" alt="&#x27;CONFIGMGR DUPLICATE RESOLUTION&#x27; section" width="252"><figcaption></figcaption></figure>

\
The Duplicate resolution tool helps you identify and clean up duplicate ConfigMgr applications created by earlier Publisher versions or manual configuration.

The **INTUNE TENANT MISMATCH CHECKER** section contains the **Tenant mismatch checker**, which you can run by clicking **Open Mismatch Checker**.

<figure><img src="../../../.gitbook/assets/image (1447).png" alt="&#x27;INTUNE TENANT MISMATCH CHECKER&#x27; section" width="256"><figcaption></figcaption></figure>

The Intune Tenant Mismatch Checker helps you identify apps that may have been published to the wrong Intune tenant by comparing your publishing history with actual tenant data.

This tool helps you find mismatched, orphaned, or misplaced applications across all configured tenants.
