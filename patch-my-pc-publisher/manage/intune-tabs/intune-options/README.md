# Intune Options in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Intune Options** tab of the **Intune Apps** and **Intune Updates** tabs of Patch My PC (PMPC) Publisher allows you to configure various options for how Publisher interacts with Microsoft Intune.
