# Tenant Icon section of Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **TENANT ICON** section on the **Intune Options** tab of Patch My PC (PMPC) Publisher lets you configure an icon for this Intune tenant to be shown in the tenant picker.

## To configure an icon

1. Click **Upload Icon**
2. Browse to the location containing the required icon (the supported file types are shown in the **TENANT ICON** section) and select it.\
   \
   The icon appears.
