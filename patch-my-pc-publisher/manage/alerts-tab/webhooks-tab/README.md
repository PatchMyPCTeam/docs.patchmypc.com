# Webhooks tab of Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Webhooks** tab in Patch My PC (PMPC) Publisher allows you to configure Publisher to send Webhook notifications to external messaging systems such as Microsoft Teams workflows and Slack.
