# Overview of ConfigMgr Apps in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **ConfigMgr Apps** tab in Patch My PC (PMPC) Publisher is where you select which third-party applications to publish to Microsoft Configuration Manager (ConfigMgr). Products enabled here determine which third-party applications Publisher publishes and maintains within your environment.

<figure><img src="../../../.gitbook/assets/image (1) (1) (1).png" alt="&#x27;ConfigMgr Apps&#x27; tab" width="563"><figcaption></figcaption></figure>

Third-party applications appear in the **Software Library | Application Management | Applications** node in the ConfigMgr console.

<figure><img src="../../../.gitbook/assets/image (723).png" alt="Applications appear in the Application Management view" width="563"><figcaption></figcaption></figure>

You can configure additional behavior related to application publishing using the [Base Install Options](base-install-options/) child tab under the **ConfigMgr Apps** tab.
