# ConfigMgr Apps tab of Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **ConfigMgr Apps** tab in Patch My PC (PMPC) Publisher is where third-party applications are configured and customized for Microsoft Configuration Manager (ConfigMgr).
