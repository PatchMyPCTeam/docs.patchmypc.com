# Run ConfigMgr Application Manager in  Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

<blockquote class="wp-block-quote">
<p>**Important**</p>
<p>This article has not been updated for Version 3.x. Once it has, this banner will be removed.</p>
</blockquote>

The **Run ConfigMgr Application Manager** button in Patch My PC (PMPC) Publisher is used to view and manage applications in ConfigMgr that were created using the Publisher. It provides a centralized interface to review application properties, deployments, task sequence usage and dependency relationships before performing application cleanup.

![Run ConfigMgr Application Manager](/_images/image-(4014).png "Run ConfigMgr Application Manager")

For more information about how to use this utility, see: [ConfigMgr Application Manager](../../../../patch-my-pc-publisherv2/administration/configmgr-apps/form-controls/configmgr-application-manager.md).
