# Configuration in Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Configuration** tab of the **Sync** tab of Patch My PC (PMPC) Publisher allows you to configure various sync-related items for the Publisher service.

<figure><img src="../../../.gitbook/assets/image (1295).png" alt="Configuration tab" width="563"><figcaption></figcaption></figure>

This tab consists of the following sections:

* [Sync Priority](configuration.md#sync-priority)
* [ConfigMgr SUP Sync Options](configuration.md#configmgr-sup-sync-options)
* [Sync Status](configuration.md#sync-status)

## Sync Priority

The **Sync Priority** section contains the **Prioritize updates when publishing** option. When this option is enabled, you can configure minimum thresholds for both the severity and CVE count for updates. Any updates meeting either threshold are published first on every target device, ordered by severity, then CVE count.
