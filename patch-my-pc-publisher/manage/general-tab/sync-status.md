# Sync Status section of Patch My PC Publisher

_Applies to: Patch My PC Publisher V3.x_

The **Sync Status** section on the **General** tab of the Patch My PC (PMPC) Publisher displays the current state of Publisher synchronization.&#x20;

<figure><img src="../../../.gitbook/assets/image (4848).png" alt="&#x27;Sync Status&#x27; section" width="563"><figcaption></figcaption></figure>

This status updates in real time as products are evaluated and processed.

{% hint style="info" %}
**Note**

See the [Status](../sync-schedule-tab/sync-status.md#status) section of [Sync Status](../sync-schedule-tab/sync-status.md) for more details on the values of the **Status** field and [Run Publishing Service Sync](../sync-schedule-tab/sync-status.md#run-publishing-service-sync) for details on how to manually run a Publishing sync.
{% endhint %}
