# Overview of the Managed Service Provider feature of Patch My PC Cloud

_Applies to: Patch My PC Cloud_

The _Managed Service Provider_ (MSP) feature of Patch My PC (PMPC) Cloud allows one company (referred to as the _parent Company_) to manage another company’s Intune environment (referred to as the &#x63;_&#x68;ild Company_) using PMPC Cloud.

{% hint style="info" %}
**Note**

The MSP feature has its own special requirements, as detailed in [Managed Service Provider Requirements](requirements.md).
{% endhint %}

Once an MSP has created a child company in PMPC Cloud, they can create and manage the following:

* [Companies](manage-msps/manage-msp-companies/)
* [Users](manage-msps/manage-msp-users/)
* [Deployments](manage-msps/manage-msp-deployments.md)
* [Events](manage-msps/manage-msp-events.md)
* [Notifications](manage-msps/manage-msp-notifications.md)
* [Custom Apps](custom-apps-msp/)
