# Manage MSP Access Requests

_Applies to: Patch My PC Cloud_

Once a Managed Service Provider (MSP) has created a child company, users can request access to it by attempting to sign in to the portal using an email address that matches the one used to onboard the child company.

The parent company admin will need to navigate to the **Users** node on the relevant child company to approve or reject any access requests as detailed in [Manage Cloud Access Requests](../../../manage/settings/users/access-requests/).

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>If the child company has no existing admin users, the access request email will be sent to the parent company's admin. See [Managing MSP Notifications](../manage-msp-notifications.md) for more details on how notifications, including emails, are handled in MSP companies.</p>
</blockquote>
