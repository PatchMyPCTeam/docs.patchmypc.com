# Manage MSP Users

_Applies to: Patch My PC Cloud_

Managed Service Providers (MSPs) can manage users in both their own Patch My PC (PMPC) Cloud company and any child companies they manage using the standard [Manage Cloud Users](../../../manage/settings/users/) processes.

This includes inviting users of the child company to their PMPC Cloud portal using the [Inviting a User to an MSP Company](manage-msp-invitations.md#inviting-a-user-to-an-msp-company) process, which is different from inviting a user to a non-MSP company.
