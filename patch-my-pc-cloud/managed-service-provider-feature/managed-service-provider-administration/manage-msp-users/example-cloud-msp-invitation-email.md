# Example Cloud MSP Invitation Email

_Applies to: Patch My PC Cloud_

Whenever a user assigned the **Full Admin** role in a parent Managed Service Provider (MSP) Patch My PC (PMPC) Cloud company invites a user in a child MSP company to join, an email is automatically sent to that user.

This email contains details of the parent MSP company and the email address of the user in the parent who sent the invite. The email is sent from the [noreply@patchmypc.com](mailto:noreply@patchmypc.com) mailbox with the subject:

_**\<MSP\_parent\_company\_name>**_**&#x20;has invited you to connect**
