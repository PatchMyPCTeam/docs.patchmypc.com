# Recover an MSP Patch My PC Cloud Company

_Applies to: Patch My PC Cloud_

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>If you are trying to recover a non-MSP Patch My PC (PMPC) Cloud Company, you should follow the [Recover your Patch My PC Cloud Company](../../../manage/settings/company-settings/recover-company.md) process.</p>
</blockquote>

When a Managed Service Provider (MSP) [adds a new Child MSP Patch My PC (PMPC) Cloud company](add-a-company-to-manage-cloud-msp.md), it is created without any user accounts.

When a user attempts to sign in to a Child MSP company for which they have no user account, they will see the company listed on the **Select the Company You Want to Sign In To** screen and have the option to **Request Access**.

However, if the Child MSP Company does not contain at least one user assigned the **Full Admin and Access Management** user role, the user requesting access will see the **No Active Administrator** dialog box.

![‘No Active Administrator' dialog box](/_images/image-(4381).png "‘No Active Administrator’ dialog box")

At this point, they have three options:

* Click **Cancel** to close this dialog box.
* Click **Contact Support** to open a support case with us, asking for assistance.
* Click **recover your company**, to start the **Claim Ownership** wizard, then follow the [Recovering a Company](../../../manage/settings/company-settings/recover-company.md#recovering-a-company) section of [Recover your Patch My PC Cloud Company](../../../manage/settings/company-settings/recover-company.md).

<blockquote class="wp-block-quote">
<p>**Important**</p>
<p>To use this option, the [Enable Company Recovery](../../../manage/settings/company-settings/company-recovery.md) setting must have been enabled for this company.</p>
<p>If this option has not been enabled for the Company, the **No Active Administrator** dialog shown below is displayed, stating that all access has been lost to this company.</p>
<p>![‘No Active Administrator' dialog box](/_images/image-(4382 "‘No Active Administrator' dialog box").png>)</p>
</blockquote>

If the user at the MSP Parent Company still has access to the Child Company, they can either [Enable Company Recovery](../../../manage/settings/company-settings/company-recovery.md) for the Child Company, which will allow the company to be recovered, or they can create a user account in the Child Company for the user requesting access.
