# Create a Custom App

_Applies to: Patch My PC Cloud Custom Apps_

Patch My PC (PMPC) Cloud allows you to create your own _Custom Apps_, which are typically in-house developed.

<blockquote class="wp-block-quote">
<p>**Important**</p>
<p>If you also intend to deploy apps from our App Catalog in addition to creating Custom Apps, you must establish a connection to your Intune Tenant using the [Add an Intune Connection](../../manage/settings/connections/add-connection.md#add-an-intune-connection) process.</p>
</blockquote>

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>If you are using our on-premises Publisher, you should follow the [Publish a Custom App](../publish-a-custom-app.md) process instead.</p>
<p>Likewise, if you are a Managed Service Provider (MSP) wanting to deploy a Custom App to one or more managed companies, see [MSP Custom Apps](../../managed-service-provider-feature/msp-custom-apps/) for more details.</p>
</blockquote>

To create a PMPC Custom App, you first need to add it to our App Catalog as follows:

1. Sign in to the PMPC Cloud Portal [https://portal.patchmypc.com/](https://portal.patchmypc.com/)
2. Click **Add App** on the **App Catalog** page.

![Clicking ‘Add App'](/_images/image-(4299).png "Clicking ‘Add App’")

The Custom Apps Deployment Wizard starts.
