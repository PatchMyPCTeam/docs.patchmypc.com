# Preview features of Patch My PC Cloud

_Applies to: Patch My PC Cloud_

The following is a list of Patch My PC (PMPC) Cloud _Preview Features._

<blockquote class="wp-block-quote">
<p>**Important**</p>
<p>You need to have <a href="https://docs.patchmypc.com/patch-my-pc-cloud/cloud-administration/manage-your-cloud-company/enable-cloud-preview-features">Preview Features enabled</a> in your company in order to access them.&#x20;</p>
<p>Preview Features may not be fully functional or may contain bugs. By enabling them, you agree to accept that you may encounter some functionality issues and bugs.</p>
<p>Enabling Preview Features on a parent MSP company does not automatically enable them for child customers.</p>
</blockquote>

Links to the relevant documentation are included when available.&#x20;

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>Once a feature is released to General Availability (GA), it will be removed from the following list as it will be available to everyone.</p>
</blockquote>
