# Delete an External App from Patch My PC Cloud

_Applies to: Patch My PC Cloud_

> \*\*Important\*\*
>
> This feature is currently only available through an invitation-only Private Preview, as both it and the documentation are under development, incomplete, and subject to change.
>
> Please do not share links to these docs with others outside of the Private Preview.
>
> Once this feature is released, it will be announced, and this banner will be removed.

To delete an app from the **External** catalog of Patch My PC (PMPC) Cloud:

1. From the PMPC Cloud Portal, navigate to **App Catalog | External**
2. On the **External** catalog page, click the app you want to delete to open it's properties.

![Clicking the app you want to delete.](../../../.gitbook/assets/image-\(4541\).png)

3. On the app’s properties page, click **Delete**

![Clicking ‘Delete'](../../../.gitbook/assets/image-\(4542\).png)

4. On the **Are you sure you want to delete&#x20;**_**\<app\_name>**_ dialog box, click **Yes**

![Clicking ‘Yes' to confirm deletion.](../../../.gitbook/assets/image-\(4543\).png)

The **External** catalog page is redisplayed, showing the app has been deleted along with the **Success – Application deleted** notification.

![App deleted](../../../.gitbook/assets/image-\(4544\).png)
