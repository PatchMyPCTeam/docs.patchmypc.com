# App Catalog in Patch My PC Cloud

_Applies to: Patch My PC Cloud_

The **App Catalog** node of the Patch My PC (PMPC) Cloud Portal contains links to the various catalogs of apps supported by PMPC Cloud.

It is split into the following sections:

<table><thead><tr><th width="125" valign="top">Catalog</th><th valign="top">Contains...</th></tr></thead><tbody><tr><td valign="top">Patch My PC</td><td valign="top">The PMPC catalog of apps curated, vetted, and maintained by us.</td></tr><tr><td valign="top">Custom</td><td valign="top">Any <a href="../custom-apps/custom-apps-overview.md">Custom Apps</a> you have created and added to your PMPC Cloud Company through the Cloud Portal.</td></tr><tr><td valign="top">External</td><td valign="top">Apps from other external resources such as WinGet (a community-driven package manager that allows users to install apps and download them from a public repository on GitHub that contains metadata about the installers).</td></tr></tbody></table>

<blockquote class="wp-block-quote">
<p>**Important**</p>
<p>The **External** catalog is currently in private preview so it is not generally available.</p>
</blockquote>

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>See <a href="https://learn.microsoft.com/en-us/windows/package-manager/">WinGet</a> for more information about WinGet and [Managing External Apps](external-apps/) for more details on managing external apps with PMPC Cloud</p>
</blockquote>
