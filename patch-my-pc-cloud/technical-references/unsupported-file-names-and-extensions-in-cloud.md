# Unsupported File Names and Extensions in Cloud

_Applies to: Patch My PC Cloud_

The following are unsupported when using Patch My PC (PMPC) Cloud:

* [Custom Apps](../custom-apps/)
* [Extra Files](../deployments/deploy-app/configurations-tab/additional-tools/extra-files.md)
* [Referencing Extra Files in Scripts](../deployments/technical-references/reference-external-scripts.md)
* [Templates](../manage/settings/deployment-templates/)

### File Names

* `PatchMyPC-ScriptRunner`
* `PatchMyPC-PreventStart`
* `PatchMyPC-UINotification`
* `PatchMyPC-Enum`
* `PatchMyPC-Localization`
* `PatchMyPC-Models`
* `PatchMyPC-Sccm`
* `Package`
* `PreCommandScript`
* `PostCommandScript`
* `PreCommandllninstallScript`
* `PostCommandUninstallScript`
* `Uninstall-Software.PS1`

### File Extensions

* `*.intunewin`
