# Check Return Codes in Intune

_Applies to: Microsoft Intune_

If a Patch My PC (PMPC) Cloud deployment has been configured to use [Return Codes](/broken/pages/FjVHPN2yhI29Pv745mcA), this is how you can check that the Return Codes have been created correctly in Intune:

1. Sign in to the **Intune admin center**.
2.  Navigate to **Apps**.<br>

    ![Navigating to "Apps"](<../../../.gitbook/assets/image-(983) (1).png>)
3.  Navigate to **All Apps**.<br>

    ![Navigating to "All Apps"](<../../../.gitbook/assets/image-(984) (1).png>)
4.  Click the app if it’s shown in the results or search for it.\
    <br>

    ![Clicking the app if it's shown in the results or searching for it](../../../.gitbook/assets/image-\(3244\).png)
5.  Navigate to **Manage | Properties**\
    <br>

    ![Navigating to "Manage | Properties"](../../../.gitbook/assets/image-\(3245\).png)
6.  Scroll down to the **Program** section, under which you will find the **Return codes**.\
    <br>

    ![Scrolling down to the "Program" section to locate the "Return codes"](../../../.gitbook/assets/image-\(3246\).png)
