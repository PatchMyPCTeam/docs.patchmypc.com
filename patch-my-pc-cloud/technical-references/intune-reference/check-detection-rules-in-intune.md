# Check Detection Rules in Intune

_Applies to: Microsoft Intune_

If a Patch My PC (PMPC) Cloud Custom App has been configured to use [Detection methods](../../custom-apps/create-a-custom-app/#configure-native-detection-rules), this is how you can check these have been created correctly in Intune:

1. Sign in to the **Intune admin center**.
2.  Navigate to **Apps**.<br>

    ![Navigating to "Apps"](../../../.gitbook/assets/image-\(2922\).png)
3.  Navigate to **All Apps**.<br>

    ![Navigating to "All Apps"](../../../.gitbook/assets/image-\(2923\).png)
4.  Click the app if it’s shown in the results or search for it.<br>

    ![Clicking the app if it's shown in the results or searching for it](<../../../.gitbook/assets/image-(929) (1).png>)
5.  Navigate to **Manage | Properties**.<br>

    ![Navigating to "Manage | Properties"](<../../../.gitbook/assets/image-(930) (1).png>)
6.  Scroll down to **Detection rules** and click **Edit**.<br>

    ![Scrolling down to "Detection rules" and clicking "Edit"](../../../.gitbook/assets/image-\(931\).png)

    \
    Any configured detection rules are displayed.<br>

    ![Any configured detection rules are displayed.](<../../../.gitbook/assets/image-(932) (1).png>)
7.  Click a detection rule to display more details.<br>

    ![Clicking a detection rule to display more details](<../../../.gitbook/assets/image-(933) (1).png>)
