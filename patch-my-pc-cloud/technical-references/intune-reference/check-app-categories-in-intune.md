# Check App Categories in Intune

_Applies to: Microsoft Intune_

If a Patch My PC (PMPC) Cloud deployment has been configured to use [Categories](../../deployments/deploy-app/configurations-tab/additional-tools/categories.md), this is how you can check the Categories have been created correctly in Intune:

1. Sign in to the **Intune admin center**.
2.  Navigate to **Apps**.\
    <br>

    ![Navigating to "Apps"](../../../.gitbook/assets/image-\(983\).png)
3.  Navigate to **All Apps**.\
    <br>

    ![Navigating to "All Apps"](../../../.gitbook/assets/image-\(984\).png)
4.  Click the app if it’s shown in the results or search for it.\
    <br>

    ![Clicking the app if it's shown in the results or searching for it](../../../.gitbook/assets/image-\(985\).png)
5.  Navigate to **Manage | Properties**\
    <br>

    ![Navigating to "Manage | Properties"](../../../.gitbook/assets/image-\(986\).png)
6.  <br>

    ![List of Categories is shown in the "Category" field.](../../../.gitbook/assets/image-\(987\).png)
