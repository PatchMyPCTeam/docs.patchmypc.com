# macOS Support Overview

_Applies to: Patch My PC Cloud_

As well as Windows devices, Patch My PC (PMPC) Cloud supports deploying Apple macOS apps.

{% hint style="info" %}
**Note**

By default, support for macOS is not included in your license count until you create your first macOS deployment. However, we include them in the number of devices shown in the Portal.

The first time you deploy a macOS app, you will be prompted to accept that you understand that deploying apps to macOS devices requires you to have a valid PMPC license for each macOS device you deploy apps to. See [Deploy a macOS app in Cloud](deploy-macos-app.md) for more details.
{% endhint %}
