# Post the Migration of an App from ConfigMgr to Intune using Patch My PC Cloud

_Applies to: Patch My PC Cloud_

As you may still need to deploy migrated applications to on-premises clients through Microsoft Configuration Manager (ConfigMgr), there are no recommended cleanup actions post a Patch My PC (PMPC) Cloud migration.

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>If you want to remigrate an application, delete the deployment created by the previous migration action and [start a new migration](/broken/pages/Oz2Qh8hyXVbgyaUHC29l).</p>
</blockquote>
