# View the Properties of Patch My PC Cloud Deployment

_Applies to: Patch My PC Cloud_

To view the properties of a Patch My PC (PMPC) Cloud deployment:

1.  On the **Deployments** page, click the relevant deployment to open its properties screen.<br>

    ![A deployment's property page](/_images/image-(2709).png)
2.  To find out more details, click **More Info** to open the more info page.<br>

    ![Click "More Info" to see more information about the deployment](/_images/image-(2710).png)

    More information about the deployment is shown.<br>

    ![More information about the deployment is shown](/_images/image-(2711).png)

> \*\*Note\*\*
>
> If \[PSADT scripts]\(../deploy-app/configurations-tab/additional-tools/scripts/) have been used in a deployment, the script's name will be shown in the \*\*Configurations\*\* section of the deployment's properties.
>
> Also, if the deployment has any \[App Dependencies]\(../deploy-app/configurations-tab/additional-tools/dependencies.md), the \*\*Dependencies\*\* section allows you to view them.
>
> !\["Dependencies" section showing app dependencies]\(/\_images/image-(2979 "\\"Dependencies\\" section showing app dependencies").png>)

3. Click **X** in the top-right corner to return to the **Deployments** page, or click **Less Info** to return to the deployment’s property page.
