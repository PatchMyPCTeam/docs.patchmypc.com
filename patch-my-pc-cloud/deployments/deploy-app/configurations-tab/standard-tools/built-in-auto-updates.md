# Configure Built-in Auto Updates in a Patch My PC Cloud Deployment

_Applies to: Patch My PC Cloud_

If an app supports built-in auto-updates, the **Built-in Auto Updates** tool will be available in the Patch My PC (PMPC) Cloud deployment wizard, but the **Disable Self-Update** checkbox will be selected by default, disabling any auto-updates.

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>Although some apps may have built-in auto-updates, they may not support controlling updates by using this or a registry value. In such a scenario, this option will be unavailable.</p>
</blockquote>

To manage the settings for the **Built-in Auto Updates** tool:

1. Click the **Built-in Auto Updates** tool.

![Clicking the 'Built-in Auto Updates' tool](/_images/image-(648).png "Clicking the &#x27;Built-in Auto Updates&#x27; tool")

2. Configure the required settings.

![Configuring settings](/_images/image-(649).png "Configuring settings")



## Next Steps

If you do not want to configure any additional settings, click **Next** to move to the [Assignments](../../assignments-tab.md) tab.

Otherwise, navigate to the relevant tool to configure the required settings, which are explained in the relevant section.
