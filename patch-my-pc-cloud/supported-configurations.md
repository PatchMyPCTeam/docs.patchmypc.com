# Supported configurations for Patch My PC Cloud

_Applies to: Patch My PC Cloud_

Patch My PC (PMPC) Cloud supports deploying apps and updates to the following app types and platforms:

* [Binary Free Apps](binary-free-apps/binary-free-apps-overview.md)
* [Custom Apps](custom-apps/custom-apps-overview.md)
* [Intune Apps](intune-apps/intune-apps-overview.md)
* [ARM](arm-support.md)
* [macOS](macos-support/macos-support-overview.md)
