# Upgrade your Patch My PC Cloud License to Enterprise Premium

_Applies to: Patch My PC Cloud_

If you are an existing Patch My PC (PMPC) Cloud customer running an Enterprise Plus license, you can sign up for a free trial to try out the additional premium features we offer as part of our Enterprise Premium license.

To upgrade an existing Enterprise Plus subscription to an Enterprise Premium trial:

1. Sign in to the portal.
2. Navigate to any Enterprise Premium feature such as **Reporting**
3. Click **Upgrade Now**

![Clicking ‘Upgrade Now'](/_images/image-(3591).png)

4. On the Subscriptions page, click either:
   1. [Start 30-day trial](../../company-settings/sign-up-enterprise-premium-trial.md)
   2. [Request a Quote](request-quote.md) to request a quote for an Enterprise Premium subscription.
