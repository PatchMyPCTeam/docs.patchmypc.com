# View the Features of each Patch My PC Cloud Subscription Level

_Applies to: Patch My PC Cloud_

To view the Features for each Patch My PC Cloud (PMPC) Subscription level:

1. Navigate to **Settings | Subscription**

<figure><img src="../../../../.gitbook/assets/image (27).png" alt="Navigating to &#x27;Settings | Subscription&#x27;" width="155"><figcaption></figcaption></figure>

2. Scroll down to the **Features** section to view a list of product limits by subscription level; expand each to see more details.

<figure><img src="../../../../.gitbook/assets/image (29).png" alt="&#x27;Features&#x27; section" width="563"><figcaption></figcaption></figure>
