# Try Enterprise Premium Features for 30 Days with Enterprise Plus

_Applies to: Patch My PC Cloud_

{% hint style="success" %}
**Note**

This article describes how existing Enterprise Plus customers can try Enterprise Premium features for 30 days while continuing to use their Enterprise Plus license. This is different from starting a trial of Patch My PC Cloud.

If you already have an Enterprise Plus license, enter your existing license key when setting up Patch My PC Cloud. You can then start a **30-day trial of Enterprise Premium features** from within the Cloud Portal.
{% endhint %}

To start a trial of Enterprise Premium features, locate a Premium feature in the Cloud Portal.

Premium features available for evaluation are identified by a diamond.

<figure><img src="../../../../.gitbook/assets/image (1515).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**Note**

**Upgrade Now** will not permanently change your license SKU.
{% endhint %}

Select **Upgrade Now** to go to the **Subscription** page, where you can start a **30-day trial of Enterprise Premium features**.

<figure><img src="../../../../.gitbook/assets/image (1516).png" alt=""><figcaption></figcaption></figure>

On the **Start Trial** screen, select **Start Trial**.

<figure><img src="../../../../.gitbook/assets/image (1517).png" alt=""><figcaption></figcaption></figure>

On the **Your 30-day trial has started** screen, click **Close**

<figure><img src="../../../../.gitbook/assets/image (3556).png" alt="Clicking ‘Close’ on the ‘Your 30-day trial has started’ screen" width="349"><figcaption></figcaption></figure>

{% hint style="info" %}
**Note**

The 30-day trial provides access to all Enterprise Premium features, allowing you to explore the additional functionality included with Enterprise Premium while continuing to use your Enterprise Plus license.
{% endhint %}

During your trial, a countdown is shown at the top of the portal indicating the number of days left on the trial.

<figure><img src="../../../../.gitbook/assets/image (1518).png" alt=""><figcaption></figcaption></figure>

Once the trial expires, Enterprise Premium features become unavailable and appear blurred again. You cannot start another trial of Enterprise Premium features.

To continue using Premium features, [request a quote](../subscription/license/request-quote.md) and purchase an Enterprise Premium subscription.

{% hint style="success" %}
**Tip**

If you decide to upgrade to Enterprise Premium, we recommend [requesting a quote](../subscription/license/request-quote.md) before your 30-day trial expires.
{% endhint %}
