# Add a Deployment Template in Patch My PC Cloud

_Applies to: Patch My PC Cloud_

To add a new Deployment Template in Patch My PC (PMPC) Cloud:

1. Navigate to **Settings | Templates**

![Navigating to 'Settings | Templates'](/_images/image-(3621).png "Navigating to &#x27;Settings | Templates&#x27;")

2. Click **Add Template** in the header and select the relevant OS for which this template will apply.

![Clicking 'Add Template' in the header and selecting the relevant OS this template will apply to](/_images/image-(570).png "Clicking &#x27;Add Template&#x27; in the header and selecting the relevant OS this template will apply to")

3. On the **Add Template** screen, enter a unique name for the template in the **Template Name** field.

![Entering a unique name for the template in the 'Template Name' field](/_images/image-(3649).png "Entering a unique name for the template in the &#x27;Template Name&#x27; field")

4. On the **Configurations** page, configure the various Tools and configuration settings for how you want apps that use this template to be deployed.

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>See [Configurations](../../../deployments/deploy-app/configurations-tab/) for more information about each option.</p>
<p>If any configuration options mentioned on the [Configurations](../../../deployments/deploy-app/configurations-tab/) section are missing from the **Templates** page, it is probably because the specific feature(s) the option relates to have not been enabled in your PMPC Cloud company.</p>
</blockquote>

5. Click **Next** to move to the **Assignments** tab.

![Click 'Next' to move to the 'Assignments' tab](/_images/image-(3650).png "Click &#x27;Next&#x27; to move to the &#x27;Assignments&#x27; tab")

6. On the **Assignments** tab, click **Add Assignment** and select the relevant assignment type from the dropdown.

![Clicking 'Add Assignment' and select the relevant assignment type](/_images/image-(3314).png "Clicking &#x27;Add Assignment&#x27; and select the relevant assignment type")

7. Configure the assignments to be used when deploying an app using this template.

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>See [Assignments](../../../deployments/deploy-app/assignments-tab.md) for more information about each Assignment Type.</p>
</blockquote>

8. Click **Save** to save the Template.

![Clicking 'Save' to save the Template](/_images/image-(3315).png "Clicking &#x27;Save&#x27; to save the Template")

The **Templates** page is redisplayed along with the **Success - Template “<**_**template\_name**_**>" has been created** notification.

!['Templates' redisplayed along with 'Success' notification](/_images/image-(571).png "&#x27;Templates&#x27; redisplayed along with &#x27;Success&#x27; notification")

<blockquote class="wp-block-quote">
<p>**Note**</p>
<p>You can create up to a maximum of 200 templates and at the top of the screen, we show the number of templates you have created:</p>
<p>![Number of templates created ](/_images/image-(572 "Number of templates created ").png>)</p>
</blockquote>
