# Manage your Patch My PC Cloud User Profile

_Applies to: Patch My PC Cloud_

Once you have signed into the Patch My PC (PMPC) Cloud Portal, you can modify your user profile by clicking your name in the top right-hand corner and selecting Profile from the dropdown.

<figure><img src="../../../.gitbook/assets/image (667).png" alt="Clicking “Profile”" width="563"><figcaption></figcaption></figure>

The User **Profile** screen is shown, allowing you to make any required changes and save them by clicking **Save**.

<figure><img src="../../../.gitbook/assets/image (668).png" alt="Clicking “Save” to save changes" width="563"><figcaption></figcaption></figure>

The **Success – User Profile updated** notification is shown.

<figure><img src="../../../.gitbook/assets/image (669).png" alt="“Success – User Profile updated” notification" width="563"><figcaption></figcaption></figure>
