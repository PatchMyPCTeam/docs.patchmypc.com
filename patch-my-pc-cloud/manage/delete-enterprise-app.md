# Delete the Patch My PC Cloud Enterprise App

_Applies to: Patch My PC Cloud_

To delete the Patch My PC (PMPC) Cloud Enterprise App from the Azure Portal:

1. Sign in to the relevant Intune tenant using the credentials you used to onboard to Patch My PC (PMPC) Cloud.
2. Navigate to **Enterprise applications** in the Azure portal:\
   \
   [https://portal.azure.com/#view/Microsoft\_AAD\_IAM/StartboardApplicationsMenuBlade/\~/AppAppsPreview](https://portal.azure.com/#view/Microsoft_AAD_IAM/StartboardApplicationsMenuBlade/~/AppAppsPreview)
3.  Click on the **Patch My PC Cloud** Enterprise Application.<br>

    ![Azure Portal showing the Patch My PC Cloud is present](../../.gitbook/assets/image-\(2054\).png)
4.  On the **Overview** page, click **Properties**.<br>

    ![Overview page of the Patch My PC Cloud app in the Azure Portal](../../.gitbook/assets/image-\(2055\).png)
5.  Click **Delete** from the command bar.<br>

    ![Clicking "Delete" on the "Properties" page of the Patch My PC Cloud app in the Azure Portal](../../.gitbook/assets/image-\(2056\).png)
6.  Click **Yes** when prompted **Delete Patch My PC Cloud?**<br>

    ![Clicking "Yes" when prompted to "Delete Patch My PC Cloud" app from the Azure Portal](../../.gitbook/assets/image-\(2058\).png)

    \
    The **Deleting application** message will be displayed whilst the Enterprise Application is deleted.<br>

    !["Deleting application" message being displayed whilst the app is deleted.](../../.gitbook/assets/image-\(2061\).png)
7.  Refresh the Azure portal (as it doesn’t auto-refresh), which will show that the PMPC Cloud Enterprise Application has been deleted successfully.

    ![Refreshed Azure Portal showing the Patch My PC Cloud app has been deleted.](../../.gitbook/assets/image-\(2063\).png)

If you sign out and back into the same Intune tenant, you will see the **Permissions requested** prompt.

!["Permissions requested" dialog box](../../.gitbook/assets/image-\(2064\).png)
